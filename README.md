# Книжковий інтернет-магазин

React-магазин відновлює ім’я та кошик після оновлення вкладки. Вихід очищає обидва, а кнопка «Придбати» завершує навчальний сценарій покупки й очищає кошик.

## React-застосунок

З кореня проєкту виконайте в PowerShell:

```powershell
npm.cmd ci
npm.cmd start
```

Відкрийте [магазин](http://localhost:3000/) і введіть ім’я від 4 до 16 символів. Після входу доступні каталог `/books`, сторінка книги `/books/:id` і кошик `/cart`.

У тій самій директорії можна запустити тести та зібрати застосунок:

```powershell
npm.cmd test -- --watchAll=false --runInBand
npm.cmd run build
```

Збірка для [GitHub Pages](https://vikbond.github.io/prometheus-x-course-task/) використовує маршрути з `#`, щоб прямі посилання працювали на статичному хостингу.

## Самостійні HTML-сторінки

Після запуску застосунку відкрийте потрібну сторінку:

- [Авторизація](http://localhost:3000/standalone/signin/)
- [Список книг](http://localhost:3000/standalone/book-list/)
- [Окрема книга](http://localhost:3000/standalone/specific-book/)
- [Кошик](http://localhost:3000/standalone/cart/)

Самостійні сторінки використовують спільний каталог і локальні обкладинки та зберігають окремий кошик у межах вкладки. Якщо оновлюєте каталог або обкладинки, синхронізуйте копії в `public` і `public/standalone`.
